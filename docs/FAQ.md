# FAQ

The questions that come up over and over, answered in one place. It lives here
rather than inside the app so an answer can change the day something changes,
without waiting for a release to carry it.

This page is only getting started. If your question isn't here, ask on
[Discord](https://discord.gg/pecE8MTPVr) or open an
[issue](https://github.com/juananzzz/resonus/issues), and the answer gets
written in here afterwards, where the next person will find it.
